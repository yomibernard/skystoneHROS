# Security

## Status

This repository contains a **prototype with sample data**. It stores everything in the browser and has no server, no authentication and no encryption at rest. It must not be used with real staff data.

## Production requirements

Before any production use, the system must meet every "Must" control in Annex A of the BRD (SEC-01 to SEC-25), including single sign-on with multi-factor authentication, server-side authorisation, encryption, a tamper-evident server audit trail, an independent penetration test, a data protection impact assessment and a tested disaster recovery plan, aligned to the CBN Risk-Based Cybersecurity Framework for Other Financial Institutions and the Nigeria Data Protection Act 2023.

## Reporting a vulnerability

Do not open a public issue. Email Skystone's Information Security team with details and steps to reproduce. You will receive an acknowledgement within two working days.
